# Recall: Cardloop — support pages

Support and privacy pages for the iOS app **Recall: Cardloop**
(`com.olgavart.recall`), served via GitHub Pages.

- `index.html` → https://jan-curtis.github.io/recall/
- `privacy/index.html` → https://jan-curtis.github.io/recall/privacy

Both URLs are referenced from the app (`Views/SettingsView.swift`) and from
the App Store Connect listing, and must stay reachable.
